# Taxas de Rendimento Escolar — Rio Grande do Sul | 2007–2025

Painel histórico das Taxas de Rendimento Escolar do INEP.

## Abrangência

O painel apresenta:

- Brasil;
- 27 Unidades da Federação;
- 497 municípios do Rio Grande do Sul;
- escolas do Rio Grande do Sul.

## Período

2007–2025.

## Indicadores

- Aprovação;
- Reprovação;
- Abandono.

## Etapas de ensino

- Ensino Fundamental — Total;
- Ensino Fundamental — Anos Iniciais;
- Ensino Fundamental — Anos Finais;
- Ensino Médio — Total.

## Dimensões

Os resultados podem ser analisados por:

- ano;
- etapa de ensino;
- localização;
- dependência administrativa / rede.

### Metodologia

O painel documenta as definições e fórmulas oficiais das Taxas de
Rendimento Escolar.

APR = número de matrículas aprovadas.

REP = número de matrículas reprovadas.

ABA = número de matrículas que deixaram de frequentar.

As taxas são calculadas sobre APR + REP + ABA.

Ausência na fonte é tratada como NA / Sem dado e nunca como zero.
